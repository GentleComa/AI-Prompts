# AI Prompts

A simple repository of reusable AI prompts.

This repo is a structured copy/paste library I use across tools like Cursor, ChatGPT, Claude, and other LLM environments. Prompts are organized by function so they can be quickly reused, modified, and versioned over time.

---

## Purpose

- Store high-quality prompts in one place
- Avoid rewriting the same prompts repeatedly
- Improve consistency of AI outputs
- Maintain version history as prompts evolve

This is a working library. Prompts may change, improve, or be replaced.

---

## Structure

Prompts are grouped by category when helpful, but the primary goal is clarity and reuse.

Each prompt file typically includes:

- Title  
- Short description  
- The full prompt (ready to copy/paste)

---

## How To Use

1. Open the prompt file.
2. Copy the prompt.
3. Paste into your AI tool.
4. Fill in any placeholders.
5. Run and iterate.

---

## Notes

- Prompts are designed to be practical, not theoretical.
- Some prompts include structured output requirements.
- Versioned prompts may exist (e.g., original vs upgraded versions).

---

This repository is intentionally simple. It exists to make thinking faster and outputs better.
